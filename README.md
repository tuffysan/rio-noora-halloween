# 🎃 Rio & Nooras Halloweenäventyr

En mobilanpassad, interaktiv Halloween-sida på svenska med Rios spökjakt, Nooras magiska brygd och ett bus-eller-godis-spel med nio dörrar. Ljud är avstängt som standard och kan aktiveras. Inga externa beroenden.

## GitHub Pages

Öppna **Settings → Pages** i repositoryt. Under **Build and deployment**, välj **Deploy from a branch**, branch **main**, folder **/(root)** och klicka **Save**.

Webbplatsen kommer därefter att finnas på https://tuffysan.github.io/rio-noora-halloween/ .
